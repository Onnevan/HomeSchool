# HomeSchool · Matemáticas de 1.º ESO

Sitio educativo interactivo con 10 lecciones del examen: potencias, raíces, descomposición, propiedades de potencias, operaciones combinadas, raíces enteras, generaciones, cuadrados, ángulos y sistema sexagesimal.

Incluye controles interactivos, ejercicios autocorregibles, navegación por cuatro pasos y progreso local (`localStorage`).

## Publicación

En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Sitio previsto: https://onnevan.github.io/HomeSchool/

No necesita instalación ni dependencias. El progreso se almacena por navegador y dispositivo.
