# HomeSchool 3.0 — Matemáticas visuales (1.º ESO)

Curso interactivo basado en un examen de 1.º de ESO de diez ejercicios. La enseñanza sigue la secuencia **Mira → Prueba → Predice → Descubre → Escribe**: experimentación visual primero y notación matemática al final.

## Acceso
- Sitio previsto en GitHub Pages: https://onnevan.github.io/HomeSchool/
- Entrada: `index.html` en la raíz de la rama `main`.
- No necesita dependencias, compilación ni servidor.
- Si la publicación aún no aparece, revisar Settings → Pages → Deploy from a branch → main / (root), y el estado de Actions.

## Actividades
1. Agrupaciones y potencias.
2. Suelos de baldosas para raíces exactas.
3. Casas de valor posicional y descomposición.
4. Cancelación manipulable de factores.
5. Resolución por etapas de operaciones combinadas.
6. Cuadrados completos e incompletos con resto.
7. Árbol de generaciones.
8. Ampliación de una superficie cuadrada.
9. Rectas y ángulos que se pueden girar.
10. Contador sexagesimal y préstamo entre unidades.

Cada lección tiene cinco etapas, predicciones de comprensión y una pregunta de aplicación con corrección. El progreso se guarda localmente en `localStorage` del navegador: no se sincroniza entre dispositivos ni se transmite a un servidor.

## Limitaciones
Es un laboratorio educativo inicial, no un reemplazo de las clases ni un motor de geometría general. Algunos modelos visuales representan cantidades grandes a escala para evitar dibujar miles o millones de objetos.
